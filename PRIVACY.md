# Privacy Statement

## Fully Private Search Engine

This search engine is **completely private** and designed to protect your data.

### What We Do NOT Do

- ❌ We **DO NOT** log or store your search queries
- ❌ We **DO NOT** use analytics or tracking cookies
- ❌ We **DO NOT** track your IP address
- ❌ We **DO NOT** build user profiles
- ❌ We **DO NOT** share any data with third parties
- ❌ We **DO NOT** use fingerprinting or session tracking
- ❌ We **DO NOT** leak referrer information to external sites

### How It Works

Your search queries are proxied through our server to external search engines (DuckDuckGo, Bing, etc.) — meaning **external services only see our server, never you**. This is the same approach used by privacy search engines like SearXNG and Startpage.

### Privacy Features

- 🔒 **No Logging**: Zero search queries are stored on the server
- 🛡️ **Proxy Model**: Search engines see our server IP, not yours
- 🍪 **No Tracking Cookies**: No cookies used for tracking
- 📡 **No Referrer Leaks**: `Referrer-Policy: no-referrer` on all responses
- 🚫 **FLoC/Topics Blocked**: `Permissions-Policy: interest-cohort=()` header set
- 🔐 **Security Headers**: X-Content-Type-Options, X-Frame-Options, DNT
- 📝 **Open Source**: Full code transparency for audit
- 🏠 **Self-Hostable**: Run on your own infrastructure

### Data Retention

This instance does not store or retain any search data. Period.

---

**Your privacy is our priority. We believe search should be private by default.**
