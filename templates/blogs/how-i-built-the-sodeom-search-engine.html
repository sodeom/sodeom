How I Built the Sodeom Search Engine

What This Project Does

I built the Sodeom search engine to experiment with how search engines actually work behind the scenes while keeping privacy and simplicity in mind. The idea was to create a lightweight metasearch engine that pulls results from multiple sources and shows them in a clean, fast interface.

Instead of building a massive crawler like Google, Sodeom focuses on aggregating results from existing engines and presenting them in one place. This approach allowed me to learn how search requests, ranking, filtering, and result rendering work without needing huge infrastructure.

Tools and Technologies Used

The backend of Sodeom is built using Python and Flask, which made routing and request handling straightforward. I used HTML, CSS, and JavaScript on the frontend to keep the interface minimal and responsive.

For search data, the engine fetches and processes results from multiple sources such as DuckDuckGo and Bing. I also used Cloudflare for DNS and performance improvements, and Netlify for hosting some of the frontend components during early testing.

This stack helped me move fast while still keeping everything flexible for future upgrades.

Problems I Faced While Building It

One of the biggest challenges was handling rate limits from external search providers. Sending too many requests too quickly can easily get blocked, so I had to add delays, caching, and smarter request logic.

Another issue was cleaning and normalizing search results. Different sources return data in different formats, so I had to write custom parsers to make everything look consistent. SEO was also tricky, especially making sure URLs, titles, and metadata were clean and indexable.

Debugging search relevance was harder than expected, because even small changes in logic can significantly affect result quality.

How Others Can Use or Learn From This

If you want to learn how search engines work without building everything from scratch, a metasearch engine like Sodeom is a great starting point. You’ll learn about HTTP requests, scraping, APIs, result ranking, and frontend rendering all in one project.

This project is also useful for anyone interested in privacy-focused tools or alternative search experiences. You can extend it by adding image search, news results, or your own ranking algorithms.
