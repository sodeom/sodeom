/api/search (JSON search API)

Overview / /api/search /images /placeholder /ai /wiki Routes

Returns JSON-formatted search results.

Method

GET

Query parameters

Parameter Type Required Description
q string yes Search query text.
page integer no Pagination page (default 1, minimum 1).

Response

{
  "results": [
    {"title": "...", "link": "...", "description": "..."}
  ],
  "query": "example",
  "page": 1,
  "has_next": true,
  "has_prev": false,
  "total_results": 10
}

Errors

  • 400 Missing q parameter.
  • 500 Search provider or parsing errors.

Example

curl "https://sodeom.com/api/search?q=privacy+search&page=1"
