/ai (AI chat proxy)

Overview / /api/search /images /placeholder /ai /wiki Routes

Proxy to an OpenAI-compatible API via GitHub Models.

Methods

GET, POST

GET behavior

Returns the HTML page at ai.html.

POST request body

Content-Type: application/json

Field Type Required Description
message string yes User prompt text.

Response

{
  "response": "...generated text..."
}

Errors

  • 400 Missing or empty message.
  • 500 Upstream API error.

Example

curl -X POST "https://sodeom.com/ai" \
  -H "Content-Type: application/json" \
  -d '{"message":"Say hi"}'

Notes

  • Requires GITHUB_TOKEN on the server.
  • Default model: gpt-4o-mini unless overridden in server config.
